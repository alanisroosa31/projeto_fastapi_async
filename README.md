# 🚀 Fast Zero - API REST

API REST assíncrona desenvolvida durante o curso **FastAPI do Zero** (Eduardo Mendes - Dunossauro), como parte da trilha de estudos de desenvolvimento Back-end em Python. O projeto abrange desde os fundamentos de rotas HTTP com FastAPI até o deploy em produção, englobando ORM (SQLAlchemy), banco de dados PostgreSQL, migrations (Alembic), autenticação segura com tokens JWT, conteinerização com Docker e testes automatizados.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Python 3.12+
- **Framework Web:** FastAPI
- **Gerenciador de Dependências:** Poetry
- **Validação de Dados:** Pydantic
- **Banco de Dados & ORM:** PostgreSQL e SQLAlchemy (AsyncIO)
- **Migrations:** Alembic
- **Autenticação:** JWT (JSON Web Tokens) e Hash de Senhas (`pwdlib` / `passlib`)
- **Testes Automatizados:** Pytest e `TestClient`
- **Containerização:** Docker & Docker Compose
